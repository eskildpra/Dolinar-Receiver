# Project for SCIQIS(10387) by Leif, Ulrik, and Eskild


Due to the difficulties of writing in the same ipynb together, each of us had our own ipynbs we worked in throughout the project with the different graphs, the final presentation is also attached for those interested. The project aims to simulate a Dolinar receiver. Start by simulating a kennedy receiver. Look either Eskild's or Leif's notebooks for starters. They have simulation for the Dolinar receiver and their probabilities and so on. After check out Ulrik's as he has more complicated DTU HPC simulation with different types of errors.
